# Inventory Dashboard — TechNest Computers

A dashboard design and sample dataset for a small computer store (laptops, desktops, tablets, monitors, peripherals, storage, networking, printers, accessories and software).

## Contents

| File / folder | Description |
|---|---|
| `data/` | Excel source data: products, suppliers, customers, orders, purchase orders, inventory |
| `ER.md` | Entity-relationship diagram (Mermaid) with primary and foreign keys |
| `ER.drawio` | The same ERD for draw.io / diagrams.net |
| `SPEC.md` | Detailed dashboard design |
| `practice.md` | Project conventions (English, blue and light-gray palette, data rules) |

## Data

All data is **fictional** and was generated for this project. It covers 2026-01-01 to 2026-11-09 and contains 66 products, 40 customers, 300 orders and 110 purchase orders.

## Status

Data model and design are complete. The dashboard itself (HTML/JS, reads the Excel files and refreshes on every load) is not built yet.
